# Графический Дизайн + AI — IT STEP, Алматы

Адаптивный лендинг в выбранном графитово-оранжевом оформлении №3.
Контент взят с https://almaty.itstep.org/graphic-design-ai, срок согласован: **12 месяцев**.

## Запуск

Сайт работает без runtime-зависимостей. Нужен Node.js; для тестов — Node.js 24+.

```sh
node scripts/serve.mjs
```

Открыть http://127.0.0.1:4173/. Также можно использовать `npm run dev`.
Без JavaScript доступны все тексты, ссылки, программа и FAQ.

## Сборка и проверки

```sh
npm ci
npm test
npm run build
```

Сборка обновляет корневой `index.html` и готовит статическую папку `dist/`.
После изменения контента нужно повторить `npm run build`.
Сначала запустите локальный сервер, затем при установленном Chromium:

```sh
CHROMIUM_EXECUTABLE=/usr/bin/chromium npm run test:browser
```

Браузерный сценарий проверяет 360, 390, 768, 1440 px, меню и Escape, программу, FAQ, якорь консультации, отсутствие горизонтального переполнения, увеличение текста до 200% и доступность содержания без JavaScript. Результаты и снимки сохраняются в игнорируемой `work/browser-qa/`.
Доступ к оригинальным изображениям IT STEP в этом сценарии намеренно блокируется: среда запрещает этот домен, проверяется поведение при ошибке загрузки. Это не проверка доступности оригиналов в интернете.

## Где редактировать

- `src/content.js` — сведения о курсе, срок, точные исходные тексты и ссылки.
- `src/render.js` — семантическая разметка всех разделов.
- `src/page-template.html` — метаданные документа.
- `styles/site.css` — адаптивное оформление.
- `src/main.js` — меню, дополнительные модули, нижняя кнопка и обработка недоступных оригиналов.
- `assets/brand/` — исходные логотипы ШАГ и Astana Hub.
- `assets/images/` — отдельные декоративные изображения, а не скриншот макета.
- `docs/content-source.md` — карта источников, спорные формулировки и ограничения.
- `design-qa.md` — что проверено и что остаётся неподтверждённым.

## Заявки и оплата

Отправка заявок, CRM, платёжная система и аналитические интеграции **не подключены**.
CTA ведут к консультации и контактам. Телефоны используют `tel:`, почта — `mailto:`.
Никакие данные формы не собираются и сообщения об успешной отправке не имитируются.
