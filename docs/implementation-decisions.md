# Реализация и независимый обзор

## Решения во время работы

1. Использован существующий отдельный каталог задачи и согласованная ветка `codex/design-ai-landing`, без дополнительного worktree: пользовательских изменений в каталоге не было, `main` не затронут. Стоимость пересмотра — создать дополнительный worktree при необходимости.
2. Локальные вспомогательные скрипты навыка отсутствовали: этапы и проверки выполнены напрямую, журнал сохранён в рабочем каталоге. Это влияет на учёт шагов, а не поведение сайта.
3. Прямое скачивание с IT STEP запрещено политикой среды: текст прочитан через веб-коннектор, оригинальные URL изображений сохранены. Риск — загрузка оригиналов остаётся непроверенной и зависит от источника.
4. Для индивидуальных Node.js-тестов в этой среде использован `--test-isolation=none`: подтверждено реальное выполнение 15 тестов, а не только проход файла-контейнера. Стоимость пересмотра — изменить команду запуска в CI.
5. Добавлен рендеринг статического HTML при сборке: весь контент доступен без JavaScript. Стоимость — после изменения данных нужно пересобрать `index.html`.
6. Найденный локальный Chromium использован для проверки portable-версии. Эти результаты не выданы за недоступную облачную проверку Product Design. Окончательная проверка оригинальных сетевых материалов остаётся необходимой.
7. Асинхронное обновление IntersectionObserver проверяется ожиданием фактического скрытия нижней панели; преждевременное чтение состояния давало ложное падение. Ожидание ограничено двумя секундами.

## Независимый обзор

Обзор выполнен отдельным агентом по изменениям `fc8880b..a8f057e`, спецификации, плану и журналу решений. Независимо выполнены 15 тестов и проверка совпадения собранного HTML с рендерером.

- Critical: нет.
- Important: имя и размер кнопки телефона на 761–1100 px; контраст клавиатурного фокуса на оранжевом фоне.
- Исходно Minor: размер текста тем и инструментов. Повышено до Important, поскольку пользовательская аудитория 18–55 и спецификация требуют минимум 16 px для основного содержания.
- Все три замечания исправлены за один проход. Браузерные регрессии сначала воспроизвели шесть нарушений (два размера шрифта, два случая контраста, размер и имя телефона), затем прошли. Полный набор 15 тестов и браузерные проверки повторно прошли.
- Отложенных мелких замечаний нет.

## Вопросы вне независимой оценки

Точная исходная hero-секция с неизвестными кнопками, реальная доступность оригинальных изображений и окончательное визуальное соответствие через облачный браузер не объявлены проверенными. Это остаётся ограничением проверки, а не поводом подменять материалы или выдумывать текст. Выпуск в production не подтверждён; подготовлен результат для просмотра в рабочей ветке.
